Software

NX Editor

SurvivalCraft Memory Bank Data Generator (Online Tool)

This tool can be used to program the data for a variety of memory bank systems in the SurvivalCraft videogame.

Real Minecraft Clock

This shows the real time on Minecraft's sundial-like clocks for different places on earth.

Macros

Touchpad Mouse Emulator

This macro allows applications that would require a mouse to use to be operable from a laptop's touchpad, these applications include most games like Minecraft and Fortnite and CAD software like SolidWorks. It is made in AutoHotKey V1.
