Macros

Touchpad Mouse Emulator (for windows, 2026)

This macro allows applications that would require a mouse to use to be operable from a laptop's touchpad, these applications include most games like Minecraft and Fortnite and CAD software like SolidWorks. It is made in AutoHotKey V1 for Windows.

Auto Touchpad Mouse Emulator (for linux, 2025)

This Linux macro allows applications, that require the use of a mouse, to be operated from a laptop's touchpad. It allows your right hand to press mapped mouse buttons while controlling the touchpad with its thumb, it will engage when a finger rests on the touchpad and disengage otherwise to allow typing on the keyboard again. It is made in python for Linux.

PWM-key-map (2025)

This AutoHotkey script provides a method to control movement using a PWM-like keypress system. The throttle value determines the duty cycle of the keypresses, and steering is handled based on mouse position. This script allows for dynamic movement control with adjustable speed and steering intensity.
